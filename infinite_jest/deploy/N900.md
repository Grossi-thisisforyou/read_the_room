# The N900: from a factory phone to the app starting at boot

About an hour the first time. Do steps 1 to 4 **at home, on Wi-Fi with
internet**: the old Nokia software servers are gone and the community copies
only work over the internet. From step 5 on, everything works in the room with
no internet.

The app itself and its own install script are described in
[`../phone/README.md`](../phone/README.md); this page gets the phone ready for
it and puts it on the show network.

## What you need

- The N900, a **fresh BL-5J battery** (a swollen old one lifts the back cover:
  don't use it), a **wall** USB charger and a micro-USB cable.
- At home: Wi-Fi with internet. Your Mac, for copying files over USB.
- The show Wi-Fi password (the one you set on the Linksys, see [LINKSYS.md](LINKSYS.md)).

## 1. A clean start (optional)

If the phone has old apps or settings you don't trust:
**Settings > Restore original settings** (keeps installed programs), or
**Settings > Clear device** (wipes your files too). Both are safe.

A full reflash of the firmware is possible but rarely needed, and the Nokia
flasher doesn't run on Apple-silicon Macs: it needs a Linux PC and the open
source `0xFFFF` flasher. Ask Claude first if you think you need this.

## 2. Check what's already there

Open **X Terminal** (in the app menu; if it's missing, it's in Application
manager as *X Terminal*). Type, one line at a time:

```
python2.5 -c "import gtk, cairo; print 'python ok'"
which gst-launch-0.10
which sudo; ls /usr/bin/gainroot
```

| You see | Means |
|---|---|
| `python ok` | Python and the screen library are there. Skip step 4's Python line. |
| a path like `/usr/bin/gst-launch-0.10` | camera tools are there |
| `/usr/bin/gainroot` | rootsh is there (you can become administrator) |

If all three are there, go to step 5.

## 3. Add the community software catalogues (at home)

Nokia's servers are dead; the community keeps copies. On the N900, at home on
Wi-Fi with internet, open the **Browser** and visit each of these addresses.
Each one opens Application manager and asks to add a catalogue: say **yes**.

```
http://maemo.cloud-7.de/maemo5/et_al/HAM-catalogs/recommended.install
http://maemo.merlin1991.at/cssu/community-thumb/community-thumb-fremantle.install
```

Then **Application manager > menu > Application catalogs** and check that
*Maemo Extras* (`http://repository.maemo.org/extras/`, distribution
`fremantle`, components `free non-free`) is listed and ticked. If not:
**New**, and type exactly that.

Keep the addresses `http://`. The N900 can't do modern secure (`https://`)
connections, so a catalogue that only works with https won't load.

These are the most recent working addresses we could find (a guide that still
worked in Oct 2024: dt.iki.fi/nokia-n900-resurrect). We couldn't test them from
here. If one doesn't load, ask Claude to look for a newer mirror.

## 4. Install what the app needs (at home)

1. **Application manager > Download > All**, search **rootsh**, install.
2. In **X Terminal**:

```
sudo gainroot
apt-get update
apt-get install python2.5 python-gtk2 python-cairo gstreamer-tools
```

If `apt-get` says it can't find one of these names, find its exact name with,
for example, `apt-cache search pygtk` or `apt-cache search cairo` and install
that. (The Python 2.5 kit is called PyMaemo; on some catalogues the parts are
named `python2.5-runtime` or `python-runtime`.) Then run step 2's checks again.

No internet at all? Download the same `.deb` files on the Mac from the
catalogue addresses above (browse the `pool/` folders), copy them to the phone
over USB (step 5), and install them in X Terminal with `dpkg -i name.deb`,
dependencies first (dpkg says which one is missing).

## 5. The show Wi-Fi with a fixed address (in the room, or at home)

1. **Settings > Internet connections > Connections > New**.
2. Name: `infinitejest`. Type: **WLAN**. Next.
3. Network name (SSID): `infinitejest`. Next.
4. Security: **WPA with pre-shared key**, enter the password. Next.
5. Before Finish, tap **Advanced**:
   - tab **IP addresses**: untick *Auto-retrieve IP address*, then
     IP address **`192.168.1.20`**, Subnet mask **`255.255.255.0`**,
     Default gateway **`192.168.1.1`**; untick auto DNS and put **`192.168.1.1`**.
   - tab **Other**: **Power saving: Off** (steadier with old routers; the phone
     is on the charger anyway).
   - Save, then Finish.
6. **Settings > Internet connections**: *Connect automatically:* **WLAN**,
   *Search interval:* 10 minutes or less, *Switch to saved connections
   automatically* on.
7. Tap the status bar at the top, choose *Internet connection*, pick
   `infinitejest`. The Wi-Fi icon appears.

Check, in X Terminal: `/sbin/ifconfig wlan0` shows `inet addr:192.168.1.20`,
and `ping -c 3 192.168.1.10` gets answers once the Pi is on.

## 6. Install the app

As in [`../phone/README.md`](../phone/README.md):

1. USB cable from the phone to the Mac, choose **Mass storage mode** on the phone.
2. On the Mac, copy the whole `infinite_jest` folder (from the IJ USB stick:
   `IJ-BUNDLE/code/infinite_jest`) onto the phone's drive as
   **`infinite_jest_phone`**. Eject, unplug.
3. In **X Terminal**:

```
sudo gainroot
sh /home/user/MyDocs/infinite_jest_phone/phone/n900/install.sh
```

The screen turns black: *THIS ROOM IS RECORDING YOU*. From now on it starts by
itself at every boot.

## 7. Check it with the Pi

- On the phone, the small dot top right: **pale** = connected to the Pi,
  **blinking yellow** = only the backup line works, **blinking red** = can't
  reach the Pi.
- On the Pi: `ij-doctor` says **Phone: sending**.
- Restart the phone once (hold power, *Switch off*, then on) and check it comes
  back to the black screen by itself, and the dot goes pale within a minute.

## For the show

- Keep it on the **wall** charger (a computer USB port switches it into USB
  mode). Strain-relieve the cable: the N900's USB socket is famously fragile.
- Tether it (lanyard or thin steel cable) so it can be tilted but not dropped.
- Tape over the power button and camera key if visitors keep finding them.
- To get the normal phone back: hold the top-left corner 5 s, or Ctrl+Q.

## When something's missing

| Problem | Fix |
|---|---|
| `python2.5: not found` | step 4, Python line |
| The app starts but the screen stays plain grey | PyGTK/pycairo missing: step 4 |
| No camera in the log (`/home/user/.ij-phone.log`) | `gstreamer-tools` missing (step 4); then send `gst-inspect-0.10 v4l2camsrc` output to Claude |
| Dot blinks red | Wi-Fi: step 5 (address 192.168.1.20, power saving off). Pi on? `ij-doctor` on the Pi. |
| Phone keeps joining another Wi-Fi | Settings > Internet connections > Connections: delete the other saved networks |
